# Neha Bawankar — Portfolio

Personal portfolio site for Neha Bawankar — IT Technical Trainer, UX/UI Designer, and Data Analyst.

## About

A single-file, self-contained portfolio built with vanilla HTML, CSS, and JavaScript — no build step, no dependencies to install. Assets (photo, resume PDF) live in the `assets/` folder; styles are in `style.css` and behavior is in `script.js`.

Sections: Hero, Skills, Impact, Projects, Experience, Education, Certificates, Contact.

## Run locally

Just open `index.html` directly in any browser — no server required.

## Deploy

This is a static site, so any static host works. Easiest options:

- **Netlify** — drag and drop `index.html` at [app.netlify.com/drop](https://app.netlify.com/drop)
- **GitHub Pages** — push this repo to GitHub, then enable Pages in Settings → Pages (source: `main` branch, `/root`)
- **Vercel** — `vercel deploy` from this folder, or drag-and-drop at vercel.com
